# App Template Frontend

React frontend for the fullstack app template.

## Setup

```bash
npm install
cp .env.example .env
# Edit .env with your configuration
npm start
```

## Component Hierarchy

```
App.js
├── Home.js
│   ├── Content.js
│   │   ├── Left/
│   │   ├── Dashboard
│   │   └── Settings/
│   └── Login/
```
